## Overview

Rob Papen RAW is a hybrid synthesizer combining analog-modeled oscillators with a gritty distortion character, delivering powerful basses and aggressive leads with warm vintage color.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Rob Papen RAW** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Analog OSCs** | Three vintage-modeled oscillators with drift and saturation |
| **Raw Drive** | Dedicated drive circuit per oscillator for instant grit and character |
| **Filter Bank** | Multi-mode filter with self-oscillation and vowel morphing |
| **FX Section** | Tape delay, chorus, and reverb with analog-inspired warmth |
